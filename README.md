# gianlucasavino.com

Personal website of Gianluca Savino. One page, a name and a few links.

## Stack

- Vanilla HTML and CSS
- No JavaScript, no frameworks, no build step

## Structure

```
├── index.html      # The card
├── 404.html
└── css/
    └── style.css
```

## Development

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000
