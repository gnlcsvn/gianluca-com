I built an AI agent that drafts a data insight every morning

Jun 17, 2026

I publish short, data-driven insights about how AI is reshaping Switzerland and Europe. Researching, fact-checking, and writing one by hand takes most of a day. So I built an autonomous agent that does the first 90% on its own, every morning, and leaves the last 10%, the judgment, to me.

The agent picks a topic, finds the numbers, checks them against their sources, writes a draft with a chart, and drops it into a private queue. Each morning I open that queue and decide what lives. Most of what you see on this site started as one of those drafts. This piece is about how it works, and, just as importantly, where I still do not trust it.

What it makes

The unit of output is a Data Insight: one sharp, quantifiable finding, one chart, and every number traceable to a source. Small enough to read in a minute, rigorous enough to cite. The agent is tuned for a specific beat, AI's impact on work and the economy in Switzerland and Europe, but the format is general.

The pipeline

Under the hood it is not one clever prompt. It is a chain of small, single-purpose steps, each a separate headless call to Claude Code, with plain code controlling the flow between them.

Scout picks one topic that has both a real source and a genuine angle, not a rephrase of someone else's headline. Research gathers the numbers, capturing each with the exact sentence and link it came from. Verify is an independent, adversarial fact-check: a fresh agent that did not do the research and whose only job is to try to break each number. Write drafts the insight using only the numbers that survived. Gate is deterministic code that checks the draft before it is allowed anywhere near me.

How it avoids making things up

The hard problem with letting a language model write about data is that models are fluent at inventing plausible numbers. The whole design is built around one rule: fail closed. A number that cannot be traced to a source is dropped, not guessed.

That rule shows up in three places. The verifier re-reads each source itself and has to find an explicit sentence supporting the number, for the exact subject, period, and scope; no quotable line, no number. The writer is only handed the verified facts. And the gate is ordinary code, not a model, so it never reads the prose for meaning. Instead the writer has to hand it a structured list of every figure it used, each tagged with the verified claim it came from; the gate refuses the draft unless each one matches a verified value and every source link resolves, and it is lenient only when a live site blocks its automated request. As a backstop, it also sweeps the text for any number the writer never declared. There is also a clean separation between a reported number, which must come straight from a source, and a derived one, like a ratio or a per-capita figure, which is allowed only if its inputs are verified and the calculation is shown and labeled as analysis.

The first time I ran the whole thing end to end, the research step hit an error and produced nothing. The verifier did not paper over the gap or invent a finding to fill it. It noticed there was nothing to check and abstained. That was the moment I trusted the design: it would rather produce nothing than produce something false.

A human still ships it

None of this makes the agent a publisher. It makes drafts. Every morning I open the review queue, a private page only I can reach, and go through the night's work the way an editor goes through a slush pile: kill the weak topics, keep the few that are genuinely interesting.

A real example

Take the piece in Figure 1. The agent found a genuinely sharp angle on its own: Switzerland ranks first in the world for AI researchers per capita, but only fourteenth for total private AI investment. Every number was sourced. It would have been a fine post as written.

But absolute investment totals flatter big countries. A nation of nine million will always trail one of sixty-nine million on a raw total. So I added a step the agent had not: I normalized investment by population, using sourced figures, and the story flipped. Per capita, Switzerland actually out-invests the United Kingdom and Germany; the real gap is with small, dense innovators like Israel and Sweden. The agent got me to a strong, sourced draft. The reframing, the judgment about what the numbers actually mean, was the part only I could add.

Where I don't trust it

The agent produces a draft that is maybe 90% of the way there, not a finished, publishable piece. The adversarial verifier lowers the odds of a wrong or mislabeled number, but it does not remove them, so a person stays in the loop for anything that goes public. And it is deliberately narrow: one short, single-chart insight at a time, not a general research assistant. The point was never to take the human out. It was to take the grind out, and keep the judgment in.

It's open source

The whole thing is public, including the exact instructions each stage is given. If you want to see precisely what the agent is told to do, or run your own version on a different beat, it is on GitHub as the Autonomous Insight Agent. You can clone it and, fittingly, point a coding agent at it to set it up for your own topic.
